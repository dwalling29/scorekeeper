Draft-night workflow

  1. Rename the teams on Team Budgets.
  2. Use Draft Board to search, filter, and star targets.
  3. Record every winning bid on Live Draft.
  4. Watch Live Inflation, not just the opening values.
  5. Export the draft JSON periodically as a backup.

Price definitions

Base
The blended K&B value before the room starts bidding.
Target
The desired purchase price.
Live Max
The inflation-adjusted ceiling, including the K&B 5% premium.
Spread
The distance between the highest and lowest source values.

Privacy

This is a self-contained single-file app, like the Judges Beer League bowling scoresheet. Draft state stays in this browser's local storage unless you export it. There is no server or database.

A published GitHub Pages site is publicly reachable. Do not add private information to the repository.

Projection references

The site now includes the uploaded June 19 projection workbook as a separate reference. Player roles, health, suspensions, and platform values can still change, so refresh the data before the actual draft.
